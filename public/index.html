📡 감시 상태

확인 중...

1. 알림 받기 (브라우저 푸시 구독)

아직 구독하지 않았어요.

2. 전체 코트 이번 달 통째로 감시

선택한 사이트의 모든 코트, 이번 달 모든 날짜를 한 번에 감시 등록해요. 요청을 아끼기 위해 날짜별 상세 시간표는 빈자리가 실제로 늘어난 날짜만 확인합니다.

3. 특정 코트 + 특정 날짜만 정밀 감시

등록된 감시 목록

등록된 감시가 없어요.

📅 다음 7일 예약 가능 시간표

"이번 달 전체 (자동)" 감시로 등록된 코트만 여기서 볼 수 있어요. 서버가 3분마다 갱신하는 데이터를 그대로 보여주기 때문에, 빈자리가 생기거나 사라지면 이 화면도 자동으로 바뀌어요.

감시 항목을 선택해주세요.

📋 최근 변경 이력

조회할 때마다 예약 가능 시간표가 바뀐 내역이 서버의 로그 파일(data/availability-changes.jsonl)에 계속 쌓여요.

⬇ 로그 파일 전체 다운로드
아직 기록된 변경 이력이 없어요.
